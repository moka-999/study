# V2 独立网络升级工具

用于已经部署完整 OTA Bootloader 和 App 的阿波罗 V2，不适用于空白板。
不依赖正式 PC 上位机、工程源码、STM32 编译器或 ST-Link；电脑需 Python 3.10+（安装时启用 Python Launcher 或加入 PATH）。

## 操作

1. 解压整个交付包到可写文件夹，不要直接从ZIP运行。
2. 确认 RK 已停止算法、需要的 B2 温控已停止，PC/网络助手已断开 MCU。MCU保持供电和网络连接。
3. 双击 `start_v2_ota.cmd`，选 **1** 查询并输入实际 IP。工具不使用隐含地址，当前测试地址应以现场配置为准。
4. 电源逻辑状态须为 `off`，固件须健康确认；不满足时先按原正常操作流程处理，工具不会自动关电。
5. 再次打开工具，选 **2** 升级，填写 IP、选择 `v2.ota`，输入 `YES`。等待明确的版本/包标识/健康确认成功提示。

选 **3** 仅离线检查包。日志保存在工具旁 `logs` 中。默认8888端口，仅支持一个TCP客户端。

```powershell
py -3 v2_ota.py query --host <MCU_IP>
py -3 v2_ota.py inspect --package v2.ota
py -3 v2_ota.py upgrade --host <MCU_IP> --package v2.ota --confirm-idle
```

可用 `--port`、`--log-dir` 自定端口/日志目录。失败返回非零退出码。

## 注意事项

- V2入口只接受`apollo-v2-h743`，B1包会在发送前拒绝；不能用改名的bin/axf代替`.ota`。
- 查询不能证明硬件板型，必须核对目标IP。统一测试仪名称不能区分V2/B1，MCU/Boot仍执行板型二次校验。
- 电源/采样模拟、MATS假FAIL取决于所选固件的构建配置，工具不修改这些开关；无模拟标记不代表实测。
- 虚拟电源为OFF不能证明外接RK已经停止，须人工核实。工具不关RK、不清busy、不用ST-Link强制复位。
- busy时先查清在途测试；未健康确认时等待，不能绕过。新包版本必须严格更高，无同版重刷/强制降级。
- finish前断线会停止；处理原因后重新开始，从0上传，不提供跨连接续传。
- finish发送后只重连查询，不重复提交。约180秒未确认只表示结果未确认，可能仍重启、网络不通或回滚；保留日志核查，不盲目重刷。
- 健康确认至少30秒；只在0903目标包、目标版本及健康状态全部吻合时报告成功。
- CRC用于完整性检查，不是签名；只使用可信固件。初次部署及App/网口损坏仍使用SWD维护。
