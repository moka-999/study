# B1 看门狗开关与验灯固件安装

日期：2026-11-03。

## 修改与用法

`Core/Inc/board_watchdog_config.h` 集中定义 `BOARD_IWDG_ENABLE`：

| 宏值 | 行为 |
|---|---|
| `0`（当前默认） | 不启动内部 IWDG，不创建喂狗任务；用于当前验板 |
| `1` | 恢复默认任务、TCP、监测、RK四项存活监督 |

修改后重新编译、烧录。关闭时启动日志输出 `[boot] IWDG disabled (debug)`。
各任务的进度上报保留，关闭时不会据此喂狗或触发看门狗复位。Boot不启动IWDG。
本次只调整B1，V2未改；B2的SPI保活及外部复位恢复机制没有因此新增或替代实现。
关闭内部看门狗后，任务卡死不会由该看门狗自动复位。

该宏只控制软件启动，不修改Option Bytes，也不能停止旧固件已经启动的IWDG。
当前板只读确认 `IWDG1_SW=1`。从旧版首次换入时仍须处理下载暂停期间的看门狗计数；
本次使用临时调试冻结完成下载，校验后恢复原调试寄存器，再复位运行。
