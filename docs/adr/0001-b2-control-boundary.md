# ADR-0001：B2拥有底板控制权并作为SPI主机

- 状态：已接受
- 日期：2026-08-24

## 背景

B2底板连接8个B1测试单元。早期工程把链路写成“B1主/B2从、8路独立SPI”，这与确认后的B2电路框图和资源仲裁职责相反。

## 决策

- B2 MCU拥有加热及其他底板级资源的唯一实际控制权。
- B2使用一组共享SPI主机总线和8个独立CS选择8块B1；每块B1的SPI2均为从机。
- B1联调基线为Mode 0、8位、MSB优先、硬件NSS低有效；B2初始时钟为1MHz。
- B1正常RK电源/重启走PC6/PC7/PG11。B2的每槽RK复位与MCU复位仅用于异常恢复。
- 固定邮箱/帧长、精确轮询、帧映射、超时安全策略、重试/幂等、启动握手和业务命令继续待B2双方评审，不在本次实现。

## 影响

B1不能主动发起SPI时钟，也不能把CS配置为普通输出。后续通信任务必须由B2轮询触发，并在协议冻结后再实现，避免形成与B2固件不兼容的私有协议。
