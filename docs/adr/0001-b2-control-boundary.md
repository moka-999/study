# ADR-0001：PC直连B2温控，B1-B2 SPI仅保活

- 状态：已接受
- 日期：2026-08-24

## 背景

B2底板连接8个B1测试单元。温控由PC直接管理B2 MCU，B1不参与控制或转发；B1–B2 SPI只用于确认在线状态。

## 决策

- PC通过独立于B1的接口管理B2温控；B2 MCU拥有加热及其他底板级资源的唯一实际控制权。
- B2使用一组共享SPI主机总线和8个独立CS选择8块B1；每块B1的SPI2均为从机。
- B1联调基线为Mode 0、8位、MSB优先、硬件NSS低有效；B2初始时钟为1MHz。
- B1–B2 SPI只承载保活，不承载温控、状态代理或其他业务命令。
- B1正常RK电源/重启按当前BRD走PC6/PC7；PC6同时控制4V和随之启动的TPS三轨，
  PG11到TPS EN为NC但由固件按防御性总闸时序驱动；可靠关断仍由PC6完成。
  B2的每槽RK复位与MCU复位仅用于异常恢复。
- 保活载荷、周期、超时判定和启动行为继续待B2双方评审，不在本次实现。

## 影响

B1不能主动发起SPI时钟，也不能把CS配置为普通输出。后续只实现由B2轮询触发的最小保活，不得扩展成温控转发通道。
