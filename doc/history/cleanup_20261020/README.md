## 归档与校验

- [obsolete_docs.zip](obsolete_docs.zip)：48个原始文件，条目名为清理前相对于仓库根目录的路径。
- [manifest.csv](manifest.csv)：每个文件的原路径、字节数和SHA256。
- `Action=Remove`表示原件已从常用目录移出；`Snapshot`表示原件随后进行了文档编辑。

## 恢复

先把ZIP解压到一个新的临时文件夹，按manifest找到所需文件，再逐个恢复到原路径。**不要直接整包覆盖仓库**：Snapshot中是旧入口，直接覆盖会撤销清理后及后续的编辑。

查询历史可使用：

```powershell
rg --no-ignore "关键字" doc/history docs/agent_handoff_history.md
```

ZIP内部全文搜索需先解压。本次没有改固件、连接硬件、烧录、提交或推送。
