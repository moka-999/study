# MCU 当前需求基线

更新：2026-10-20。这里只保留已确认规则与尚未完成的边界；实现/验证状态统一见[任务清单](driver_tasks.md#current-status)。旧决定及整理前全文见[归档](history/cleanup_20261020/README.md)。

## 1. 职责与链路

| 对象 | 负责 | 不负责 |
|---|---|---|
| PC | 测试计划、算法参数和安全电压选择，连接各B1；通过独立接口管理B2 | 不用PC Seq替代RK事务标识 |
| B1 MCU | TCP server、PC↔RK业务转换、三轨电源/Boot/采样、信息/OTA和结果灯 | 不执行DDR测试算法，不控制或代理加热 |
| RK | 实际内存算法、进度及结果；按约定提供启动心跳 | 不由调试打印替代正式结果帧 |
| B2 MCU | 八槽底板、共享SPI主机、编号通知、全部加热及本地屏幕 | 不转发PC到B1的测试TCP数据 |

B2分别通知PC与B1温控状态。B1只接收常温/高温显示模式；实际温度控制始终在B2。B1是同级独立工程`../b1`，V2是开发验证平台，不能把V2模拟值或替代引脚当作B1实测。

### 1.1 产线IP与槽位

唯一Excel依据是`JMCT产线tester IP配置表.xlsx`第一张`IP rule`，不使用后两张工作表分配RK地址。

| 对象 | 地址 |
|---|---|
| PC | `192.168.210.9` |
| B2 | `192.168.210.(10*T)` |
| B1 | `192.168.210.(10*T+S)` |

T为testerId，范围1～21；S为siteId，范围1～8。括号为十进制计算，不是地址文本。原表E78应为`.100`、K62应为`.180`，不沿用两处笔误；原Excel未改。

- B2通过0004的可选3003 TLV发送testerId；B1自己读PB5:PB4:PB3原始码0～7并加1，V2使用`B2_TEST_SITE_ID`默认1。
- B1 PB3～5输入、无内部上下拉；B1外部4.7kΩ上拉，B2按位贴0Ω接地。111也有效，槽位编码不代替B2的SLOT_ONLINE#。
- 收到合法状态交换时重读槽位；已有有效testerId，且testerId或槽位变动才切IP。siteId不是B2请求的可写字段。
- 联调掩码255.255.255.0，网关0.0.0.0，TCP端口8888。改IP时若PC已连接或测试/电源/OTA在途，整包busy，旧配置保留；相同地址不重配。
- 配置只在RAM，不写FRU。复位后、首次B2通知前暂用本地测试`192.168.1.201`；多个未配置板同时上线会冲突，产线隔离/发现流程仍须联合确定。
- IP成功生效后，PC结果siteId使用相应槽位字符串；未配置时仍使用FRU本地标签。siteId和mirrorIndex无关。
- V2保留历史固定MAC；B1按UID派生稳定的本地管理单播MAC，量产MAC分配与FRU替换策略仍待确定。

代码链路见[B2接入记录](b2_spi_integration_20261020.md#31-siteid到ip的实际调用链)。

## 2. 三套协议边界

| 协议 | 当前规则 | 依据 |
|---|---|---|
| PC↔MCU | 单客户端TCP:8888；18字节大端头+JSON，总长≤4096；Version=1、Flag=8、ServiceID=0；双方发送Seq独立递增、不回显 | [PC协议](pc_tcp_protocol_spec.md) |
| MCU↔RK | 5A/A5帧；Modbus CRC16；TLV头大端、Value多字节整数小端；下行独立u64 Seq，上行使用最近收到的MCU Seq | [RK协议](protocol_spec.md) |
| B2↔B1 | 独立SPI帧/事务，B2共享总线主机、每槽独立CS；0004统一状态交换；应答回显B2请求Seq | [SPI协议](b1_b2_spi_protocol.md) |

PC坏头有界逐字节恢复，完整坏JSON回0006后继续；半帧字节间空闲超过500ms或丢弃预算超限才断连。详见[TCP恢复](pc_tcp_recovery_20260929.md)。PC Seq首值/重连/回绕目前按实现的1/归1/回绕0使用，最终双方确认边界不因已有测试自动获得批准。

RK只有一个测试在途，不自动重发；进度是5001+3016同帧，最终结果是3/5/7 TLV原子包。失败明细9001地址后紧跟3001 die，die为0/1且唯一；无明细者PASS，零地址不得自动当无错。结果窗口匹配不能保证识别被RK重新标成当前Seq的旧结果。

B2 Mode0、8位MSB、硬件NSS低有效，初始1MHz。V2用SPI3，B1用SPI2；AD7124分别用SPI2/SPI4，不争抢总线。业务状态经队列由TCP上下文顺序应用，B2收发不混入RK任务。

## 3. 测试、灯态与采样

- PC先0106 `{}`建立整轮，再串行FUNC 0103/0105或SLT 010A/010B，最后0107提交`errorchip`失败数组。070x已删除。
- FUNC 0105顶层共享siteId和measurementData；testResults两条mirrorIndex=0/1，testStatus为0 FAIL、1 PASS；resultDesc承载首错地址/errorType，physicalAddr暂为空。
- mirrorIndex表示镜像分组，可包含多芯片；physicalAddr用于镜像内物理芯片定位。现行RK硬件只对应两颗die，不从错误地址擅自推导新映射。
- 0107镜像0/1/2映射两组LPDDR/eMCP结果灯，未知镜像拒绝。提前结束整轮只废弃结果，不取消RK或提前解除busy；断线后不凭index认领旧结果。
- SLT仅接收slt/memtest86，algorithmIndex=null；每次受理均重新启动，准备电源/Boot后由PC回010B整次结果，不等待RK心跳或自行判断EDK。
- `TimingParameters`允许部分字段，只保存受理请求的RAM副本，不跨请求合并、不写Flash；尚未下发RK，不宣称应用成功。
- PARA 0108/0109保留。IDD状态/激励由RK实现，MCU负责电压和测量；测试条件、保持窗口、限值/判定及结果合同尚未闭环。
- 0602提供采样快照及统计，测试中可查询；0105汇总本次有效采样的均值、样点最大/最小值。B1三轨共轨电流是同轨负载之和，不能分离两颗电流，也不能把样点最大值当作全带宽瞬态峰值。
- 0106按B2已知模式显示：常温双通道闪、高温FAIL通道闪，未知灭；每相亮/灭500ms。轮内允许局部更新；0107后只缓存模式，不覆盖最终PASS/FAIL。
- PG6初始化完成后常亮表示MCU正常上电，非RK电源或网络状态；三组灯的实际颜色等B1验收。

## 4. 真实电源和板型差异

`power`是DDR训练目标，三轨以十进制字符串mV输入。VDD1原生10mV步进、VDD2/VDDQ原生5mV步进，必须精确可编码，不取整。PC确认安全电压/三轨组合，MCU校验TPS物理范围；寄存器可写范围不等于安全训练范围。

FUNC的电压/Boot变化或reboot=true触发冷重启；成功配置可复用，明确未改硬件的拒绝不丢失原配置标记。SLT每次重启是独立规则。外部已启动路径为power:null、bootMode:null、reboot:false；B1仍须软件电源状态ON。

PC6控制RK806/TPS共享4V，PC7控制系统3.3V；PG11 NC不提供独立DDR关断。B1使用已确认的可调时序初值，默认OFF，本轮普通心跳表示初始化完成；初版直接关电，不等RK关机应答。训练前调压时间余量、反灌/放电与写盘安全仍待真实硬件/RK验收，见[初版配置](b1_power_business_20261013.md)。

| 项目 | B1 | V2 |
|---|---|---|
| 电源/测量 | 真实驱动，PAC分流20mΩ；精度待验收 | 可显式启用电源/Boot/测量模拟，PAC测试参数10mΩ |
| MATS假FAIL | 禁止 | 显式联调选项，只改第一颗PC结果，第二颗真实 |
| RK协议口 | UART4→RK UART0_M0 | USART1 |
| 日志 | USART2接收RK UART2_M0_DEBUG；USART1选择输出MCU或RK日志 | 不照搬B1串口分工 |
| PHY | 最新B1资料按YT8512H、PG12复位核对 | YT8512C、开发板复位路径 |

详细引脚/BOM依据见[引脚表](b1_mcu_pinout.md)。B1实际料号、贴装、地址和模拟输出不能由静态检查代替。

## 5. 信息与OTA

- 版本/FRU/测试仪信息的PC响应每次读取W25Q256持久记录；编译常量只供初始化、打包、自检，不能直接作为正常响应数据源。
- 0101 `{}`查询、0102返回testerName/testerVersion/testBoard，不在连接后主动推送。当前默认JMCT-4000 / D00 / RK3588_test；保留定制FRU及已确认迁移规则。
- 完整OTA使用内部B/A1/A2、W25下载/稳定恢复包、版本/CRC检查、健康确认和失败回滚。当前实现、分区及测试依据见[OTA设计](ota_design.md)、[Flash布局](flash_layout.md)。
- 0901～0903沿用`mcu_begin/write/finish/query/cancel`；原始块上限3000字节、完整TCP PDU≤4096，按begin返回值分块。
- 两个RK固件区各8MiB，仅预留空间及`rk_*`接口，当前返回notSupported，不写RK固件。
- B在线更新、签名/加密、差分升级、人工降级和跨连接/断电续传不在当前实现范围；升级前仍需空闲维护条件。
