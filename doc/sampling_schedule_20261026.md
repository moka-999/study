# 电压与电流独立采集调整

日期：2026-10-26。范围为B1与V2正式监测代码；V2内存模拟保持原有500ms波形周期。本记录不代表真板采样精度或持续速率验收。

## 已确认的取舍

- 电流以保持测量精度为前提提速，先消除软件长等待；不减少转换位数、不跳过数据稳定等待或异常检查。
- AD7124保留全功率、内部2.5V基准、增益1、Sinc4、FS=384。连续单通道输出率50 SPS；当前三通道顺序切换，约80ms/通道、240ms/完整扫描，另有读取及调度延迟。
- PAC1934保留连续单极性、1024 SPS寄存器配置、16位VSENSE原始码。其低速档通过转换间休眠降速，转换周期本身相同；本次不为提速改量程或转换精度。REFRESH_V后仍实际等待至少1ms并核对ACT/LAT，完整读取成功才发布。

依据：[AD7124-4 Rev.E](https://www.analog.com/media/en/technical-documentation/data-sheets/ad7124-4.pdf)的Sinc4/通道切换说明；[PAC193x DS20005850E](https://ww1.microchip.com/downloads/en/DeviceDoc/PAC1931-Family-Data-Sheet-DS20005850E.pdf)§4.1.4、4.1.7、4.2及DC特性。

## 执行流程

仍使用原监测任务，没有新增RTOS任务：

1. 电源ON后初始化器件；已就绪器件不重复初始化，失败器件限频重试（间隔至少1s）。非ON不采样，清缓存有效位及未完成电压组。
2. 每轮先采PAC电流；AD每10ms尝试读取一次已有转换结果，未就绪立即返回，不再阻塞等待收齐三路。
3. AD按通道号收齐三路才发布新电压组；收齐前可以查询上一完整组，但不会再次计入统计。错误或扫描超过1s则丢弃部分组并清有效位。
4. TPS读清状态每1s单独读取；它不随电流每次读取，也不作为健康状态对PC公开。
5. ON每轮让出1个RTOS节拍，实际电流读取周期还包含I²C事务、REFRESH_V等待、AD探测和调度耗时。未标定成“1ms一个完整样本”。非ON等待20ms。

电源控制、DAC和采样仍共用事务锁。正常AD转换等待已移出持锁路径；器件初始化、故障超时和控制请求仍可能造成采集间隙。离线验证不能替代总线负载测量。

## AD7124初始化校准

按本轮确认，只补校准接入；不增加采样诊断统计，不改成分阶段故障恢复。

`memory_monitor_init()`沿用原入口调用`ad7124_init()`：复位及ID检查 → 三路setup/通道配置 → 清初始化错误 → CH0、CH1、CH2依次内部零位校准 → 全部成功后启动连续扫描。每路使用独立setup，每次仅启用待校准通道。当前增益1保留芯片出厂GAIN，不执行不支持的内部满量程校准。

初始化校准每路最多500轮就绪查询，事务间实际等待至少1ms，SPI及调度耗时另计；不能把500轮当成严格500ms期限。Sinc4/FS384的单路零位校准约80ms，三路加寄存器备份/恢复会延长首次电压就绪时间。公开维护接口仍保留低速配置所需的20000轮预算。

任一路校准或恢复失败，立即结束初始化并使ADC句柄失效，不交付部分校准结果；监测层保持电压未就绪，按原有限频流程完整重试。首次上电和故障重新初始化会校准，正常采样与PC查询不会反复校准；已就绪的PAC不重置。校准系数由AD寄存器使用，不写W25，也不增加PC字段。

这是ADC内部零点校准，不替代电压前端、PAC分流电阻或整板的标准源标定。依据AD7124-4 Rev.E第53页校准说明及第55页Sinc4建立时间表；实际耗时及效果待真板确认。

## 统计与PC响应

- 电压、电流各自按实际采集起止时间过滤窗口、去重并计数。只统计本轮新完成/失败的组；AD暂未就绪既不重复计数，也不记作测量失败。
- 电流使用µA整数累加，均值输出按sum/count后换算mA，保留原先整数mA截断丢失的信息。µA存储单位不等于承诺1µA硬件准确度。
- PC命令、JSON字段名和单位不变：`currentMa`及电流Ave/Peak/Min仍是mA的JSON number，可能带小数；电压仍是mV。平均值是已采样点的算术平均，最大/最小值是已采样点的极值。
- `0601`只复制快照，不触发器件读取；`0105`继续使用本次测试冻结的统计。`sampleAgeMs`取有效电压/电流中较老的采集起点，不因读到新电流就把旧电压年龄清零。缓存超过1s或电源非ON时不作为有效测量返回。
- B1保持20mΩ分流、1.01倍电压分压补偿和真实SPI4采样；V2保持10mΩ验证参数、未绑定正式AD片选及既有模拟开关。未接真实传感器的V2不能验证精度。

## 验收边界

到板后用标准电流/电压源对比零点、增益、噪声及温漂，确认分流电阻贴装/误差、PAC SLOW引脚、AD参考和输入网络。1024 SPS是芯片配置，不是已实测的MCU读取率；PAC不是保存全部电流采样的FIFO。

SLOW引脚若为高会覆盖为8 SPS，不能凭软件刷新次数宣称获得同等数量独立转换；须先核对真实引脚与时序。当前统计按软件读取窗口过滤，AD连续转换的积分起点不等于函数调用时间，不宣称与RK命令边界硬件同步。

记录持续电流读取间隔、三路电压扫描时间、错误/丢样、总线占用及网络/RK并发负载。不能用软件提高读取频率保证捕获所有短脉冲，也不把本次采集调度当成已完成JEDEC IDD算法/硬件同步窗口。
