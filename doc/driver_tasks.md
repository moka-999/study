# B2 板驱动开发任务清单 + 开发流程

### 设备架构（20260819 澄清：8×B1 + 1×B2）

```
B2 底板 (母板, 8 槽)
 ├─ 槽1 → B1 #1 = STM32H743 + RK3588 + DDR + 电源监控(自管3路)
 ├─ 槽2 → B1 #2 = 独立完整单板, 结构同上
 ├─ ...     每个 B1 都是独立单元
 └─ 槽8 → B1 #8 = 同上
```

- **B1** = 完整单板：STM32H743 + RK3588 + DDR，自带电源监控（TPS62868×3 + PAC1934 + AD7124），自管本板 3 路 DDR 电压/电流
- **B2** = 底板母板：8 个 B1 插槽 + 共享资源（ETH 切换 SN74LVC1G3157×8、供电、BMC console）
- 之前解析的 MB360 原理图引脚（AD7124 SPI4 PE11-14、TPS62868 I2C1/2/4、PAC I2C4 PH4/5）即**单块 B1 上的 STM32 外设**
- **网络拓扑（架构A）**：每块 B1 独立 IP（.201-.208），各自 TCP:8888；PC 按 IP 区分槽位，**连接即槽位 → TLV 命令无需 slot 字段**
- 每块 B1 固件相同；IP 按槽位差异化配置（拨码/底板读取，待 B2 定）
- 现有 ddr_power/PAC/AD7124 均按单板 3 路设计 → 无需改 24 路

> 唯一任务来源（AGENTS.md「下一步」引用本文件）。
> 原理图依据：`docs/MYZR-RK3588-ZUOYI_SCH_20260811.pdf`（当前最新，含引导模式新增电路）。
> 引脚依据：本文件 §9 引脚总表（几何法从原理图提取 + H743 AF 校验）。

## 0. 开发阶段与流程

### 阶段一：阿波罗 V2 开发（现在 → B2 板到货前）

> 目标：**所有驱动的代码层全部完成并在 V2 上跑通**（协议/寄存器/时序逻辑），B2 只留"引脚重映射 + 真机标定"。

```
V2 可验证的：
  · GPIO 逻辑（PC6/7/PG11/PH8-10 翻转时序）
  · I2C 总线 + 真实芯片模块（TPS62868 / PAC1934T / MCP4725 用模块/杜邦线挂 V2 的 I2C1/I2C3）
  · SPI 总线 + 真实 AD7124 模块（挂 V2 SPI2）
  · TLV 命令接入 + python 测试脚本（协议层全部可测）
V2 不可验证、留给 B2 的：
  · 电源真时序标定（t1/t2/t3、3V3_MCU 来源、EN 默认态）
  · Boot 模式与 RK reboot 集成
```

### 阶段二：B2 真板（B2 到货后）

> 目标：引脚重映射 + 实测标定 + 与 RK3588 真机联调。

```
1. CubeMX 重配引脚（SPI4 PE11-14 / I2C1 PB7-8 / I2C2 PF0-1 / I2C4 PH4-5 / UART4 PA11-12 / USART2 PD5-6）
2. 新增 i2c_if/spi_if 工厂实例（B2 引脚），驱动零改动（hal_if.h 设计保证）
3. 万用表/示波器标定：电源时序、DAC 电压-模式映射
4. 真机联调：UART4/USART2 → RS0102 → RK3588
```

### 每任务 4 步闭环（阶段一内）

```
① 手册/原理图确认 → ② 编码(ninja 零警告) → ③ V2+模块验证 → ④ 测试脚本入库
```

**流程纪律**：
- 每任务一个 commit：`驱动代码 + 测试脚本 + 本文件更新` 一起提交
- 未定项用 `#define` 开关兜底，B2 实测后翻转
- 原理图版本变更 → 先跑 `tools/sch_netlist.py` 对比，再动驱动

### 上电/拉偏时序设计（20260819 定稿）

**阶段规则（两阶段电压策略）**：

| 阶段 | 电压行为 | 规则 |
|------|---------|------|
| ① 上电/初始化 | 启动电压→标称值 | 单调爬升、无瞬时过压（靠选料：启动电压≤标称） |
| ② 运行老化测试 | 标称↔拉偏（±5%/-10% 有加有减） | 双向随意调，无单调要求（测试 DDR 容限） |

**关键约束：初始化窗口期电压必须=标称且稳定，禁止拉偏。**

**上电时序**（EN 低时 I2C 不可读写+寄存器复位，手册 8.4.1）：
```
1. PG11 拉高(EN) → 芯片 soft-start → 启动电压 (0.5/0.9/1.2V)  ← 窗口躲不掉
2. I2C 可访问 → 立即 ddr_power_init() 清STATUS + 写VOUT + ramp 20mV/µs
3. 电压 ramp 到标称 (1.8/1.1/0.6V) 几百µs
4. 稳定后 RK 才允许 DDR 初始化
```
无需软件关闭：软件使能(bit5)会重新走 start-up（先启动电压再VOUT），不能消除窗口。

**RK 复位恢复**（拉偏中 RK 复位 → DDR 在错误电压初始化会失败）：
```
主动复位(TLV REBOOT): 先 ddr_power_set(标称) → 等稳定 → 拉复位脚
被动复位(RK崩溃): hb_task 心跳超时检测 → 立即恢复标称 → 等 RK 自行重启
复位后: 初始化前电压必须标称, 初始化完成才允许再拉偏
```

**料号选择约束**（决定因子，BOM 确认）：
- VDD1=1.8V → x2C（因子2，启动1.2V）
- VDD2=1.1V → x1C（因子1，启动0.9V）
- VDDQ=0.6V → x0C（因子0.5，启动0.5V）
- 原则：启动电压 ≤ 标称 → 上电单调爬升无过压
