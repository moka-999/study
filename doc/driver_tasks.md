# B1 单元 MCU 驱动开发任务清单 + 开发流程

### 设备架构（20260824 澄清：8×B1 + 1×B2）

```
B2 底板 (母板, 8 槽)
 ├─ 槽1 → B1 #1 = STM32H743 + RK3588 + DDR + 电源监控(自管3路)
 ├─ 槽2 → B1 #2 = 独立完整单板, 结构同上
 ├─ ...     每个 B1 都是独立单元
 └─ 槽8 → B1 #8 = 同上
```

- **B1** = 完整单板：STM32H743 + RK3588 + DDR，自带电源监控（TPS62868×3 + PAC1934 + AD7124），自管本板 3 路 DDR 电压/电流
- **B2** = 底板母板：8 个 B1 插槽 + 共享资源（ETH 切换 SN74LVC1G3157×8、供电、BMC console）
- **B1–B2 SPI拓扑**：B2 MCU使用一组共享SPI主机总线（SCK/MOSI/MISO）和8个独立CS，每个CS选择一块B1 SPI2从机；该链路只做保活，不传温控或其他业务命令。
- 之前解析的 MB360 原理图引脚（AD7124 SPI4 PE11-14、TPS62868 I2C1/2/逻辑I2C4、PAC逻辑I2C4 PH4/5）即**单块 B1 上的 STM32 外设**；PH4/PH5按软件开漏GPIO实现，不是STM32 I2C4 AF引脚对
- **网络拓扑（架构A）**：每块 B1 独立 IP（.201-.208），各自 TCP:8888；PC 按 IP 区分槽位，**连接即槽位 → TLV 命令无需 slot 字段**
- 每块 B1 固件相同；IP 按槽位差异化配置（拨码/底板读取，待 B2 定）
- 现有 ddr_power/PAC/AD7124 均按单板 3 路设计 → 无需改 24 路

> 唯一任务来源（AGENTS.md「下一步」引用本文件）。
> 原理图依据：`docs/MYZR-RK3588-ZUOYI_SCH_20260811.pdf`（当前最新，含引导模式新增电路）。
> 引脚依据：本文件 §9 引脚总表（几何法从原理图提取 + H743 AF 校验）。

> **状态口径（2026-08-24 审计）**：`代码`、`V2 实测`、`B1 实测`、`B1/B2 联调`分开记录。当前新驱动只有代码和自检入口，不等于外接模块或真板验证。总览见 [`README.md`](README.md)。

```
  · 电源真时序标定（t1/t2/t3、3V3_MCU 来源、EN 默认态）
```

### 阶段二：B1真板验证及B1/B2联调（硬件到货后）

> 目标：引脚重映射 + 实测标定 + 与 RK3588 真机联调。

```
1. ✅ 已建立同级独立`../b1`工程（含SPI4 PE11-14 / I2C1 PB7-8 / I2C2 PF0-1 / 逻辑I2C4 PH4-5软件开漏GPIO / UART4 PA11-12 / USART2 PD5-6），不再与V2混合构建

4. 真机联调：UART4/USART2 → RS0102 → RK3588
```

### 每任务 4 步闭环（阶段一内）

```
① 手册/原理图确认 → ② 编码(ninja 零警告) → ③ V2 Mock+波形验证 → ④ 测试脚本入库
```

**流程纪律**：

## 3. TPS62868 DDR 电源（I2C1/2/4）

**手册**：TI SLVSFS3B。寄存器 VOUT1=0x01/VOUT2=0x02/CONTROL=0x03/STATUS=0x05。最新图面是 **A版VSET/PG电阻配置**，不能继续按C版固定地址0x42处理。VOUT换算：`code=(VOUT/因子-400mV)/5mV`，code 0x00-0xFF 对应400-1675mV×因子。

| U4026 / VDD2 | **TPS628681A**, x1A = 1 | **86.8kΩ**（对应TI标称86.6kΩ档） | 0.90V | **0x41** | 1.10V |

### 上电/拉偏时序设计（20260819 定稿）

**阶段规则（两阶段电压策略）**：

| 阶段 | 电压行为 | 规则 |
|------|---------|------|
| ① 上电/初始化 | 启动电压→标称值 | 单调爬升、无瞬时过压（靠选料：启动电压≤标称） |
| ② 运行老化测试 | 标称↔拉偏（±5%/-10% 有加有减） | 双向随意调，无单调要求（测试 DDR 容限） |

**关键约束：初始化窗口期电压必须=标称且稳定，禁止拉偏。**

**上电时序**（EN 低时 I2C 不可读写+寄存器复位，手册 8.4.1）：
```
1. PG11 拉高(EN) → 芯片 soft-start → 启动电压 (VDD1=1.60V / VDD2=0.90V / VDDQ=0.50V)  ← 窗口躲不掉
2. I2C 可访问 → 立即 ddr_power_init() 清STATUS + 写VOUT + ramp 20mV/µs
3. 电压 ramp 到标称 (1.8/1.1/0.6V) 几百µs
4. 稳定后 RK 才允许 DDR 初始化
```
无需软件关闭：软件使能(bit5)会重新走 start-up（先启动电压再VOUT），不能消除窗口。

**RK 复位恢复**（20260821按P12/P17/P18/P22/P24重审）：
```
主动复位(TLV REBOOT): 设置Boot DAC(如需) → pwr_ctrl安全下电 → 延时 → 按上电时序恢复
硬复位手段: PC6关闭/开启VCC4V0_SYS，使RK806 PMIC断电重启；不使用PG12
复位后: DDR三轨必须按标称值初始化，RK初始化完成后才允许再次拉偏
```

- P24的`PWRON_L`只接人工按键SW9到GND，未发现MCU驱动路径。
- PC7/PC6/PG11的关断顺序、上电顺序、最小掉电时间，以及重新上电后是否还需触发`PWRON_L`，必须在真板上用示波器/逻辑分析仪确认。
- 心跳超时不能立即无限自动断电重启；需定义次数上限、冷却时间和PC可见故障状态。

**料号选择约束**（决定因子，BOM 确认）：
- VDD1=1.8V → TPS628692A / x2A（因子2，56.2kΩ档启动1.60V）
- VDD2=1.1V → TPS628681A / x1A（因子1，86.8kΩ按TI 86.6kΩ档启动0.90V）
- VDDQ=0.6V → TPS628681A / x1A（因子1，15.4kΩ档启动0.50V）
- 原则：启动电压 ≤ 标称 → 上电单调爬升无过压

## 8. LED 结果显示 + W25Q256/版本信息

### 8.1 LED 结果显示

- 最新原理图是三颗红绿双色灯（两路同亮为橙）+ 两颗单色绿灯。PG0–PG6控制三颗双色灯和单色LED4；另一个单色LED5由`CPU_GPIO_PWR`控制，不属于PG0–PG6。
- 当前 Apollo V2 驱动是 PB0/PB1 低有效，仅能用于开发板心跳/连接灯，不能靠改两个宏直接变成最终结果灯。
- 三颗双色灯统一语义：红常亮=FAIL可取件、绿常亮=PASS可取件、橙闪=常温测试中禁止开治具、红闪=高温测试中且防烫。
- 三颗双色灯分别用于两组LPDDR4/4X和一组eMCP；物理灯号顺序待板级配置确认。
- 两颗单色灯用于上电/板卡状态，具体语义待定；B1 MCU只控制其中LED4/PG6。
- 所有闪烁状态统一为亮500ms、灭500ms（完整周期1秒，50%占空比）。
- 软件提供业务状态接口，由驱动转换为颜色与闪烁；三颗双色灯与具体测试对象的物理映射留在板级配置中。

**当前实现（2026-08-24）**：`led_result_render()`已把5种状态转换为独立的红/绿开关信号，不绑定V2或B1引脚。离线合同、正式镜像和独立`build_led_wave/test.elf`均构建通过，波形镜像已通过SWD烧入Apollo V2。两颗单色灯语义未冻结，本轮不猜测、不实现。

**V2六路波形镜像**：Apollo V2的PG0/PG1/PG2/PG4/PG5被核心板FMC等网络占用且未完整引出，不能直接复制B1 PG0-PG5。测试镜像使用底板P2-23至P2-28六个连续排针，仅验证颜色语义、独立通道和500ms闪烁：

| 逻辑分析仪 | V2接点 | 模拟功能 |
|---|---|---|
| D0 | P2-23 / PD7 | LPDDR4/4X #0 红 |
| D1 | P2-24 / PD3 | LPDDR4/4X #0 绿 |
| D2 | P2-25 / PD2 | LPDDR4/4X #1 红 |
| D3 | P2-26 / PC12 | LPDDR4/4X #1 绿 |
| D4 | P2-27 / PC11 | eMCP 红 |
| D5 | P2-28 / PC10 | eMCP 绿 |

执行`powershell -ExecutionPolicy Bypass -File tools/dev.ps1 led-wave-build`生成镜像。断电重上电后先保持全低2s，随后循环：全灭1s → LPDDR0绿常亮2s → LPDDR1红常亮2s → 三组红绿同步500ms亮/灭共4周期 → 三组红色500ms亮/灭共4周期。橙闪阶段会让D0-D5全部出现高电平，可同时验收六路物理连线。测试前不得插入摄像头、LCD、SD卡或其他占用这些复用网络的模块。通过V2波形验收后才把业务逻辑移植到B1独立工程并实装PG0-PG5。
