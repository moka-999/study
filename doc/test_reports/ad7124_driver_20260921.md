# AD7124 驱动修正与验证（2026-09-21）

范围：修复V2/B1共用AD7124驱动的确定软件缺陷，不修改PC/RK线格式、引脚、供电时序或IDD判限，不增加启动自动校准。

## 修正内容

| 问题 | 修改后约定 |
|---|---|
| 稀疏通道数据按got前缀换算，可能读未初始化值 | 16位有效掩码收集CH0..num_ch-1；全部收齐才交付并换算。IF_OK才可用，任何失败保持调用方输出原值；got仅供诊断。 |
| 轮询/数据状态中的错误被忽略 | STATUS和DATA尾部状态均检查ERROR_FLAG；通信/器件错误返回IF_ERR，未就绪或未收齐返回IF_TIMEOUT。采样不主动读ERROR清除诊断证据。 |
| 单次转换未核对通道 | 连续与单次模式均匹配CH_ACTIVE；单次不暗中重触发，批量单次只允许num_ch=1。 |
| 校准不检查保存、操作、恢复和超时 | 先完成全部备份再写；逐项检查；失败尽力恢复旧OFFSET/GAIN及通道/模式；恢复失败置UNKNOWN、num_ch=0，要求重新初始化。 |
| 内部满量程校准条件错误 | 增益1仅零位校准并保留工厂增益；增益>1先OFFSET=0x800000，再低/中功耗满量程、零位校准；全功耗临时改中功耗，结束恢复原控制值。 |
| 滤波参数uint8_t截断高位 | 改uint32_t原始bit23..16位图，拒绝夹带FS、保留类型1/3/6和非法FS；9.6Hz的FS改2000。 |

每次采样最多500轮1ms等待，校准每阶段最多1000轮，另加SPI调用耗时；这不是严格墙钟期限或电源安全时序。极低采样速率可能合法超时，不据此判断器件损坏。未新增ERROR_EN配置，未声称检测所有模拟故障。

校准依据为[ADI AD7124-4 Rev.E原厂手册](https://www.analog.com/media/en/technical-documentation/data-sheets/ad7124-4.pdf)第53–54页；状态/控制第81–83页、滤波第91页。核对了本地原版PDF文本及53/54/81/82/91页原图，不按旧驱动注释推定器件要求。

本次只同步纯AD驱动及中文接口合同。V2 SPI2、B1 SPI4的绑定保持原样；B1采样层1.01分压还原、PAC 20mΩ和V2 PAC 10mΩ均保留。

## 验证结果

- 两板实际AD7124 C代码 + 实际memory_monitor C代码，在Cortex-M7 QEMU上执行通过；SPI寄存器是故障注入桩，不是真实器件。
- 覆盖乱序、缺首/中/尾通道、重复、16通道、容量/空指针/NaN、STATUS/DATA错误、部分读取失败、就绪超时、单次错通道；失败不覆盖哨兵输出。
- 覆盖增益1只校零位、逻辑CH15校准、增益>1临时中功耗、正常路径每个SPI读写故障点、满量程/零位超时及持续IO失败。读取备份失败不得写，恢复不可信不得继续采样。
- 组合采样层实测坏ADC不置电压有效位，也不丢弃独立有效的PAC桩电流；两板正确保留不同分压换算。此项不是PAC硬件测试。
- 两板普通Debug、V2隔离Mock、V2及B1 UART4/UART2 OTA开启且896KiB槽限的Release构建通过。Mock只构建，未烧录运行；未覆盖旧实板镜像目录。
- V2 PC协议24项、边界19项及纯接口头、RK模型96项、电源/LPDDR/Boot模型、B1完整check通过；两板实际monitor/MCP Boot缓存故障回归通过。
