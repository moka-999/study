# 项目术语表

| 术语 | 本项目含义 |
|---|---|
| PC | 上位机，连接 MCU 的 TCP server 并下发测试/管理命令。 |
| MCU | STM32H743，负责带外管理、TCP↔串口网关、电源与采样外设。 |
| RK | RK3588，从 MCU 串口接收内存测试命令并返回结果。 |
| 阿波罗 V2 | 当前开发/模拟板，用 CH340、测试 GPIO、Mock 和逻辑分析仪验证代码逻辑，不等同于最终 B1/B2。 |
| B1 | 单个测试单元：STM32H743 + RK3588 + LPDDR + 三路 DDR 电源/监测。 |
| B2 | 8 槽母板/底板；每槽插一块独立B1，并有一颗负责全部加热和底板级控制的B2 MCU。 |
| B2 MCU | B2上的控制器，由其他同事开发；通过SPI与各B1 MCU通信。 |
| eMCP | 将eMMC与移动内存集成的封装；本项目第三颗双色结果灯用于其测试状态。 |
| 带外管理 | 不依赖 RK 正常业务软件的电源、复位、监测和诊断能力。 |
| 中位机网关 | MCU 在 PC TCP 与 RK UART 之间解析、排队、转发和匹配 TLV 帧。 |
| TLV | Type-Length-Value 帧内单元；当前命令容器实现为 `Type=0x5000`。 |
| CmdID | 命令编号，当前为 TLV Value 的前 2 字节。 |
| Seq | 64 位序列号；PC Seq 用于 PC 侧匹配，MCU→RK 使用独立递增 Seq。 |
| pending | MCU 已发往 RK、等待响应的命令槽，当前最多 4 条。 |
| ACK / BUSY | MCU 已接收入队 / 转发队列已满，状态值分别为 `0x03` / `0x04`。 |
| VDD1 / VDD2 / VDDQ | LPDDR4/4X 的三路 DDR 电源，目标标称值暂记为 1.8V / 1.1V / 0.6V，最终以 BOM 和实测为准。 |
| 代码完成 | 只表示源码/API 存在且可编译。 |
| V2 验证 | 当前指阿波罗 V2 上的Mock、离线测试与逻辑分析仪波形验证；没有外接目标芯片模块。 |
| B1/B2 验证 | 在最终硬件上完成引脚、电气、时序、标定与全链路测试。 |
