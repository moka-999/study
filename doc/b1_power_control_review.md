# B1 电源控制核对与训练电压方案

更新：2026-09-14。范围：B1电源核对、用户确认的开发预设及V2/B1训练目标底层实现。已修改源代码并完成编译/离线检查；没有烧录、推送或进行实板测试。

## 1. 结论与适用边界

**B1 具有独立控制 RK 上下电、设置启动模式和调整 DDR 三轨电压的电路路径；不能因 B1 没有独立 RK 复位 GPIO，就断言必须由 B2 配合。**

但是，“可以调压”不等于“已经保证在目标电压下训练”。本次用户接受的开发预设是：MCU先运行并准备参数，PC6开启4V后，能在RK806自动启动、RK开始DDR初始化前完成TPS目标写入及稳定。先据此推进软件；是否有足够的最坏情况余量仍待实板证据，不把预设当成测量结论。

本文电源部分取代旧资料中“PG11 必然是三轨硬件总闸”“PC7 可单独阻止 RK 训练”“训练必须等于标称电压”等表述。仅训练目标底层已实现；新开始测试JSON已写入协议，字段解析、自动电源循环和RK就绪闭环仍未接通。

## 3. 已确认的实际控制路径

| 功能 | 原理图路径 | MCU 能做什么 / 不能据此认定什么 |
|---|---|---|
| MCU 独立供电 | P17：12V经U4005产生`VCC_5V0`；P21：U4产生`3V3_MCU` | 本板12V已建立后，MCU不依赖PC6/PC7开启即可运行；可先准备总线及启动参数。不是说整机12V断开后MCU还能工作。 |
| RK/TPS 4V 电源 | P18：PC6→R7263（0Ω）→U4003 MP8759 EN→`VCC4V0_SYS`；P12给RK806供电，P22给三颗TPS供电 | PC6是RK电源循环的关键控制。TPS与RK806同时取得输入电源，不是两路独立开关。EN还有电阻偏置，不能把MCU复位高阻期等同于软件已拉低。 |
| 系统3.3V电源 | P17：PC7→R4020（1kΩ）→U4004 RT8070 EN→`VCC3V3_SYS` | 可开关这条系统电源，但它不是`3V3_MCU`，也不是RK806产生的`VCC_3V3_S3`；关闭PC7不能作为“RK尚未运行”的证明。P13的`BIG/NPU_EN`取自后者。 |
| TPS使能 | P22：R4074/R4080/R4085（10kΩ）把各EN拉向4V；PG11串联位R4073/R4081/R4086标NC | 按图面贴装时，TPS随4V自动启动。PG11只是防御性预留，不能承担实际调压窗口控制或独立关断保证。 |
| RK自动开机 | P12：4V→R2216（200kΩ）→`PMIC_VDC`，R2217（200kΩ）/C2265（1nF）接地，连接RK806 VDC | 存在随4V触发PMIC自动开机的硬件路径；正常电源循环不应预先认定必须模拟面板按键。实际门限、上电斜率及重新启动仍需验收。 |
| RK复位 | P12：RK806 RESETB→`RESET_L`；P2：该网接RK3588 NPOR；P24：引到J36 pin22 | PMIC上电序列完成后释放RK。未找到B1 STM32直接控制该网的GPIO，不能宣称MCU可以无限期保持RK复位；PG12是PHY复位。 |
| 启动介质 | P24：MCU I2C2→U4030 MCP4725→R7288→`BOOT_SARADC_IN0`，DAC由`3V3_MCU`供电 | 可在RK受控上电前设置Boot电压。软件写入成功不等于RK最终确实从指定介质启动，仍需RK启动结果确认。 |

`PWRON_L`人工按键、J35整板12V软开关、PC6控制的RK/TPS电源循环是不同层级。B1已经获得12V时的正常RK重启，不应和B2把整个site送上电混为一谈。B1–B2 SPI仍只保活，不因本方案增设B2电源业务。

### 实际贴装的前置条件

1. P22的U4025 VSET电阻R7289仍画为249kΩ；用户已要求改为56.2kΩ。按TPS628692A，二者对应启动电压/7位地址分别为2.30V/0x46和1.60V/0x49。图纸不能证明整改已落地，必须以最终贴装和回读确认；不能盲目改软件地址以掩盖VSET错误。
2. U4026图面86.6kΩ，用户确认86.8kΩ，按TI的86.6kΩ识别档核对；U4027为15.4kΩ。按预期料号/电阻，三轨默认启动值为1.60/0.90/0.50V，地址为0x49/0x41/0x4F。这些是硬件启动值，不是训练完成后的实际测量值。
3. P22三路输出串联位R4100/R4101/R4102仍标NC。必须核实最终实际供电选路，确认TPS输出确实接到被测电源轨，且不会与另一稳压源直接并联。本记录不授权不经核对就补焊0Ω。

## 4. `power` 需求如何落到执行过程

用户已明确：继续使用一条开始测试指令，按2026-09-14最新反馈以“大类＋名称”标识算法，不单列小类；同时保留`algorithmIndex`作为当前测试计划内的算法项编号，MCU回带供PC对齐结果并推进计划，不把它当作RK算法ID。保留是否重启和Boot模式，重启统一受控断电，不再单列类型。`power`表示本次DDR初始化和训练时应使用的目标电压，不是训练结束后才施加的拉偏。字段见[PC协议4.7节](pc_tcp_protocol_spec.md#47-开始测试0x0103)：大类/名称/index、内存类型＋三路有符号steps、`reboot/bootMode`。每路目标mV＝标称mV＋steps×20，固定标称基准不受当前读数影响；V2/B1文档同步，固件仍只解析旧名称/编号，新业务尚未迁移。

- PC选择适用的安全电压；MCU也须校验电压范围、步进、内存类型和三轨组合，不能只信任PC下拉框，更不能把TPS寄存器可写范围当成测试安全范围。
- 电源配置改变时执行受控断电重启。以MCU判断为准，PC的“不重启”不能绕过这条规则；不是运行中先改电压、再决定要不要重启。
- 比较对象应是完整、规范化后的配置与上一份成功生效且仍有效的配置，不能比较JSON字符串或上一次请求。首次状态未知、MCU复位或上次操作失败时，不可据旧缓存判定无需重启。
- Boot选择表示FSPI/eMMC/SD等启动选择；电源循环表示如何重启，两者分别处理。Boot改变是否强制重启及命令兼容策略尚待协议确认，不单侧删掉现有设置命令。
- 只有完成目标供电和约定的RK就绪确认，才能将该配置记为成功并开始测试。I2C成功、`pwr_ctrl=ON`和“RK已在目标电压下训练成功”不是同一件事。

## 5. B1独立执行的候选顺序

以下为目标流程。用户已接受其中“训练前配置赶得上”的开发预设，但不是批准具体毫秒参数；当前实现范围见§6。

1. **准备**：MCU保持运行，校验本次请求；提前准备I2C和Boot目标。若RK正在运行，先停止测试并取得安全掉电确认；确认方式由RK协议承载，不能用TCP仍在线代替。
2. **受控掉电**：按最终认可的PC6/PC7关断顺序执行，并验证RK和DDR真正完成放电；PG11为NC时不作为三轨已经关闭的依据。故障强制关断与正常掉电分开记录。
3. **断电期间**：等待最小掉电窗口，在RK未启动时设置Boot DAC；提前准备三轨目标码及必要采样，不等PC6上升后才进行无关初始化。
4. **开始上电**：按批准的系统电源顺序动作。PC6使4V建立时，TPS和RK806开始各自的启动过程；TPS尚未可访问时不能提前写I2C。PC7不是用于暂停RK的独立闸门。
5. **训练前配置**：在已验证的时间预算内完成三轨目标写入、必要读回和稳定判定。目标是本次训练电压，而非先强制标称、启动后再拉偏。此时不能插入长延时、日志、无关采样或长时间总线锁等待。
6. **RK初始化/训练**：RK806自行释放RK复位，RK按Boot选择启动，DDR初始化和训练期间保持目标电压不变。闭源DDR bin本身不否定外部供电预置方案，但其实际训练行为仍需联调确认。
7. **测试或故障**：成功就绪后进入对应算法；调压失败、超时或训练未成功均不可上报“配置完成”。若无法在截止时间前完成或安全撤销供电，本候选方案不能被批准，不能以“通常很快”替代失败路径保证。

### 必须证明的时间关系

从PC6开启这一受控起点计算，应验证：TPS最长可访问等待 + 三轨事务最坏耗时 + 稳定时间 + 调度/容差余量，小于RK最早开始DDR初始化的时间。保守方案以原图`RESET_L`释放前完成为界，但这不是LPDDR `RESET_n`本身，仍要验证DRAM侧复位/CKE与电压关系。

RK806手册描述VDC触发后按序上电，最后释放RESETB；这为候选窗口提供依据。图4-3中的检查时间、通道间隔和上限不能简单相加，尤其不能把`T≤16ms`或检查超时100ms当成MCU保证可用的最短时间。实际RK806型号/启动配置和板上VCCA/VDC波形必须纳入验证。[依据：RK806 §4.1.2及表4-1](https://atta.szlcsc.com/upload/public/pdf/source/20240126/65179706C318B50B43978A8DF1ADA832.pdf)。

TPS在EN低或掉电后不能靠事先I2C写入保留任意目标；启动先采用电阻识别值，具备访问条件后再由MCU调整。不能将EN保持低当成“先配置、后放行”方案。[依据：TPS §8.3.4、§8.4.1和§8.4.3](https://www.ti.com/lit/ds/symlink/tps62869.pdf)。

### 标准约束不能被复位等待替代

LPDDR4的JESD209-4E §3.3要求三轨建立顺序及相对电压关系；从任一电源首次达到300mV到全部进入规定范围的`tINIT0`不超过20ms，电压建立后DRAM `RESET_n`仍需满足至少200µs低电平。实际DRAM输入脚状态也有约束。因此，即使RK可多等一会，也不能把DDR长期停在1.60/0.90/0.50V默认值上。

“必须在标称值训练”是旧软件策略，不是上述标准要求每次必须精确等于典型值。训练目标是否合规取决于被测器件/标准、板级约束、误差余量及全程波形。三颗TPS同时取得EN也不自动证明三轨爬升顺序正确；LPDDR4X需另核对适用条件。

## 6. 实现范围与剩余差距

| 位置 | 本次读到的现状 | 与新需求的差距 |
|---|---|---|
