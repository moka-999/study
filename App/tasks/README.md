# FreeRTOS任务目录

- `pc/`：维护PC TCP连接、PC帧接收和响应发送。PC请求的u32 `Seq`必须由对应响应原样回显。
- `rk/`：维护MCU-RK串口、TLV、u64 `Seq`、pending和重传。
  `rk_link.h`声明共享队列及序号分配入口，计数器仅在实现内维护；心跳与RK任务不直接读写对方的全局变量。
- `common/`：LED、采样监控等不专属于PC或RK链路的正式任务。
- `test/`：W25Q256自检、驱动Mock、逻辑分析仪波形等隔离验证任务。它们只能由测试构建开关创建，不得被当作生产业务入口。

PC与RK任务后续应通过业务适配层交换结构化数据，禁止直接传递对侧原始帧或混用Seq。当前正式PC JSON任务尚未接入历史`pcToRk_Queue/rkToPc_Queue`，不能把队列存在当作业务已经打通。
